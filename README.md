# 📊 SuperStore Sales Dashboard - Power BI Project

## 📌 Project Overview

This project showcases an interactive and insightful **Sales Dashboard** built using **Power BI**, based on the popular SuperStore dataset. The dashboard visualizes and analyzes key metrics such as total sales, profits, quantity sold, customer segments, top-performing regions and states, product categories, and monthly trends. It provides business intelligence that helps stakeholders make data-driven decisions.

---

## 🧾 Dataset Information

- **File**: `SuperStore_Sales_Dataset.csv`
- **Data Range**: 2019–2021
- **Fields Included**:
  - Order Date
  - Region & State
  - Sales, Profit, Quantity
  - Category & Sub-Category
  - Customer Segment
  - Ship Mode
  - Payment Mode

---

## 📈 Dashboard Features

- **Sales by Region**: Compare sales performance across Central, East, South, and West regions.
- **Sales & Profit by State**: Identify high-performing and underperforming states.
